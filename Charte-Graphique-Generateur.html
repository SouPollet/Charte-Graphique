    Aperçu

    L’aperçu se met à jour pendant la saisie. Les contenus marqués « exemple » sont à remplacer par les vôtres.

    Configuration de la charte

    Copiez ce texte pour sauvegarder votre charte (images comprises), ou collez une configuration enregistrée puis chargez-la.

    Exporter la charte

    Une fois la charte terminée, enregistrez-la en HTML pour la joindre à un prompt Claude Code, ou en PDF pour la partager. Chaque enregistrement demande votre confirmation.

    1. Fichier HTML complet, pour Claude CodeLes slides, un bloc JSON structuré (couleurs, polices, logo, motif, tokens de design) et vos images en fin de fichier. À enregistrer sous charte.html, puis à joindre à un futur prompt pour développer l’application mobile.
    2. Fiche texte seule (Markdown)Légère, sans image : à coller directement dans un prompt.
    3. PDFToutes les slides, une par page paysage. Le texte n’est pas sélectionnable : pour Claude, préférez le HTML. Si l’enregistrement direct est indisponible, ouvrez le fichier HTML dans Chrome, faites Ctrl+P (Cmd+P sur Mac), choisissez « Enregistrer au format PDF » et cochez « Graphiques d’arrière-plan ».
